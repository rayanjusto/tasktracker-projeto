
# TaskTracker

## Descrição
O TaskTracker é uma aplicação de linha de comando desenvolvida em Python para cadastrar e visualizar tarefas.

## Funcionalidades
- Cadastro de tarefas.
- Registro de título e descrição.
- Definição de prioridade.
- Registro de data limite.
- Status inicial automático como Pendente.
- Listagem das tarefas cadastradas.
- Validação dos dados informados.

## Tecnologias utilizadas
- Python 3
- Git
- GitHub

## Estrutura do projeto
- `src/main.py`: código-fonte da aplicação.
- `docs/planejamento_logico.pdf`: planejamento lógico da Fase 1.
- `.gitignore`: arquivos ignorados pelo Git.
- `README.md`: documentação do projeto.

## Como executar
1. Instale o Python 3.
2. Abra o terminal na pasta do projeto.
3. Execute:

```bash
python src/main.py
```

Caso o comando `python` não funcione no Windows, tente:

```bash
py src/main.py
```
